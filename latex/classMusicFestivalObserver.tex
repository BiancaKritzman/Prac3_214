\doxysubsection{Detailed Description}
Common interface for festival components that can receive notifications. 

This class acts as the Component participant in the Composite design pattern. Both leaf objects and composite \doxylink{classZones}{Zones} can be treated uniformly through this interface.

It also provides the interface used by the Observer pattern for receiving festival notifications.

Adds a child component. 

Design decision\+: The add operation is included in the common Component interface so that both Composite objects and leaf objects can be treated uniformly. Composite objects use this operation to add children, while leaf objects implement it as a no-\/op because they cannot contain children.

This allows clients to work with both leaves and composites through the same \doxylink{classMusicFestivalObserver}{Music\+Festival\+Observer} interface without needing to know the concrete type of the object.
