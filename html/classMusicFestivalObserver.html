Detailed Description

Common interface for festival components that can receive notifications.

This class acts as the Component participant in the Composite design pattern. Both leaf objects and composite Zones can be treated uniformly through this interface.

It also provides the interface used by the Observer pattern for receiving festival notifications.

◆ add()

virtual void MusicFestivalObserver::add ( MusicFestivalObserver *  child)
pure virtual

Adds a child component.

Design decision: The add operation is included in the common Component interface so that both Composite objects and leaf objects can be treated uniformly. Composite objects use this operation to add children, while leaf objects implement it as a no-op because they cannot contain children.

This allows clients to work with both leaves and composites through the same MusicFestivalObserver interface without needing to know the concrete type of the object.

◆ remove()

virtual void MusicFestivalObserver::remove ( MusicFestivalObserver *  child)
pure virtual

Removes a child component.

Design decision: Leaf classes implement this operation even though they cannot have children. This maintains a consistent interface for all components in the Composite hierarchy. A leaf therefore provides a no-op implementation rather than requiring clients to check whether an object is a leaf or composite before calling remove().
