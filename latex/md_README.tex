A music festival where everything functions smoothly, the Sound\+Teams gets messages when artists are done performing so they can call the new artists up on stage. There are max capacities for each stage and when that capacity is reached then the gates for that stage will be closed. The gates stay open if the stage is not at max capacity yet. There are different zones inside the music festival, the vendor zone has refreshments and merch stands. If merch goes up for sale there will be a message sent to the \doxylink{classSoundTeam}{Sound\+Team} and they will make an announcement saying that there is merch for a specific artist. If there is theft then there will be a message sent to the security team and they will be deployed in the \doxylink{classVendorZone}{Vendor\+Zone} to try stop the thief. There is also a way to get the Schedule for all the artists when there is an update of the schedule.\hypertarget{md_README_autotoc_md4}{}\doxysection{\texorpdfstring{Doxygen}{Doxygen}}\label{md_README_autotoc_md4}
