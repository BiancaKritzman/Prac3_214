\doxysubsection{Detailed Description}
Represents the festival security team. 

\doxylink{classSecurity}{Security} is a leaf participant in the Composite pattern because it does not contain child festival components.

\doxylink{classSecurity}{Security} also acts as an Observer by responding to theft reports and dispatching security to the affected zone.
